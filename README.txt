WILDERZONE - WEB BUILD
=======================

Upload this whole folder (index.html, Build/, TemplateData/, StreamingAssets/) to the site and keep it together.
Open index.html over http(s), not from disk: browsers block WebGL loads from file://.
The files are gzip-compressed with a fallback, so any static host works with no server settings.
This is the ARCADE EDITION: ENDLESS and its high scores only. It has no multiplayer and no other modes, on purpose.
The top ten on THIS MACHINE is kept in the browser's storage. THE WORLD is Unity's leaderboard, shared by every player
of every copy of the game; it shows 'not switched on yet' until the board is made (see Docs/PLAY_WITH_A_FRIEND.md).
The game starts on the LOW graphics level in a browser; OPTIONS can raise it.
